1. Общие положения

Настоящая Политика разработана в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных» и определяет порядок обработки персональных данных и меры по обеспечению их безопасности, принимаемые Оператором.

Оператор обрабатывает персональные данные лиц, заполнивших форму записи на сайте, а также иных лиц, обратившихся к Оператору по вопросам оказания услуг.

2. Перечень обрабатываемых данных

  • Имя (фамилия указывается по желанию).
  • Контактный телефон.
  • Адрес электронной почты — если указан добровольно.
  • Имя пользователя в Telegram / VK — если указано добровольно.
  • Ответы, выбранные при прохождении квиза (вокальный профиль, предпочтения по графику).
  • Технические данные: IP-адрес, тип браузера, время визита (через сервисы аналитики, если используются).

3. Цели обработки

  • Запись на бесплатную диагностику голоса и связь с пользователем для подтверждения времени.
  • Информирование о расписании, переносе и иных вопросах оказания услуг.
  • Направление информационных сообщений о новых программах студии (с возможностью отписаться в любой момент).
  • Соблюдение требований законодательства Российской Федерации.

4. Правовое основание обработки

Обработка персональных данных осуществляется на основании добровольного согласия субъекта персональных данных, выражаемого путём проставления соответствующей отметки при отправке формы на сайте, а также в целях исполнения договора оказания услуг.

5. Передача данных третьим лицам

Для целей записи на занятие и связи с пользователем данные могут передаваться следующим обработчикам:

  • ООО «Сенлер» — сервис рассылок и автоматизации в социальной сети ВКонтакте (сервер расположен на территории Российской Федерации). Используется для приёма заявки и отправки уведомлений.
  • Telegram Messenger Inc. — для приёма уведомлений о новых заявках в Telegram-бот Оператора. Пользователь информирован, что серверы Telegram могут находиться за пределами Российской Федерации.
  • Google LLC — для загрузки шрифтов на странице (Google Fonts). При этом передаётся только IP-адрес посетителя, без иных персональных данных.

Иным третьим лицам персональные данные не передаются. Данные не используются для целей трансграничной передачи в государства, не обеспечивающие адекватной защиты, без отдельного согласия субъекта.

6. Сроки обработки и хранения

Персональные данные обрабатываются и хранятся в течение всего срока, необходимого для целей обработки, но не более 3 (трёх) лет с момента последнего взаимодействия с пользователем. По истечении срока данные удаляются или обезличиваются.

Согласие может быть отозвано пользователем в любой момент путём направления соответствующего запроса по контактам Оператора, указанным выше.

7. Меры по защите данных

  • Использование протокола HTTPS на всех страницах сайта.
  • Хранение данных на защищённых серверах указанных обработчиков с разграничением доступа.
  • Ограничение круга лиц, имеющих доступ к данным, только Оператором лично.
  • Регулярное удаление неактуальных данных.

8. Права субъекта персональных данных

Пользователь вправе:

  • Получать информацию об обработке своих персональных данных.
  • Требовать уточнения, блокирования или уничтожения персональных данных, если они являются неполными, устаревшими, недостоверными, незаконно полученными или не являются необходимыми для целей обработки.
  • Отозвать своё согласие на обработку персональных данных.
  • Обращаться с жалобой в Роскомнадзор (rkn.gov.ru) или в суд.

9. Использование файлов cookie

Сайт может использовать файлы cookie для технической работы и анонимной аналитики посещений. Продолжая использовать сайт, пользователь соглашается с использованием cookie. Отключить cookie можно в настройках браузера.

10. Изменения Политики

Оператор оставляет за собой право вносить изменения в настоящую Политику. Актуальная редакция всегда доступна по адресу публикации квиза.
